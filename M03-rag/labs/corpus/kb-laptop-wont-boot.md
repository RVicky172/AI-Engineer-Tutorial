# Laptop does not start

1. Connect the charger and wait 15 minutes; a fully drained battery may not show any light at first.
2. Hold the power button for 20 seconds, release it, then press it once.
3. Disconnect the docking station, external monitors and USB devices, and try again.
4. If the screen shows a BitLocker recovery screen, see "BitLocker recovery key" instead.
5. If the laptop shows the manufacturer logo and then restarts in a loop, write down any error code on the screen.
