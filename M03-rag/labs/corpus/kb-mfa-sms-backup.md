# Add a backup MFA method

Add a second sign-in method so that a dead phone battery does not lock you out.

1. Go to `https://id.acme.example/security-info`.
2. Choose **Add sign-in method → Phone** and enter your mobile number.
3. Confirm the code sent by SMS.

SMS is only a backup: your default method must remain the Authenticator app. You can also register a FIDO2 security key from the same page; ask the service desk for one if your role needs it.
