# Office printer error codes

The office multifunction printers show a code on their display. Most can be cleared at the printer.

| Code | Meaning | What you can do |
|---|---|---|
| E-101 | paper jam in tray 1 | open tray 1, remove the paper, close it firmly |
| E-102 | paper jam in the duplex unit | open the rear door, pull the paper out straight |
| E-210 | toner low | keep printing; facilities replaces toner when it reaches E-211 |
| E-211 | toner empty | report to facilities (extension 2000), not IT |
| E-340 | fuser error | switch the printer off for 10 minutes; if it returns, report to IT |
| E-404 | cannot reach print server | report to IT: the printer lost its network connection |
| E-512 | firmware update failed | do not switch off; report to IT immediately |

## After the September 2026 firmware problem
Firmware updates are now installed on one printer first, then the rest a week later. If a printer shows E-512, it was in the update wave; IT can recover it remotely.
