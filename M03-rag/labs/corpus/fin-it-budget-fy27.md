# IT budget FY2027 (Confidential)

Approved by the CFO on 25 September 2026. Figures in INR crore.

| Line | FY2026 actual | FY2027 budget | Change |
|---|---|---|---|
| Cloud (AWS) | 18.4 | 21.0 | +14% |
| Software licences | 12.1 | 12.8 | +6% |
| End-user devices | 7.6 | 6.9 | -9% |
| Network refresh | 2.2 | 4.5 | +105% |
| Project Kestrel (ERP replacement) | 0.0 | 9.75 | new |
| Security tooling | 3.3 | 4.1 | +24% |

## Notes
- **Project Kestrel** replaces the current ERP over 30 months. Vendor shortlist: two vendors, final decision in Q4 FY2026. The project is not yet announced to staff; do not discuss outside the finance and IT leadership teams.
- The network refresh replaces the VPN gateways and the Wi-Fi controllers, both end of support in 2027.
- Device spend drops because the laptop refresh cycle moves from 3 to 4 years.
