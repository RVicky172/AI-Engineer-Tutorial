# M15 · Customer-Facing Engineering Skills

**Priority:** Must have · **Roadmap week:** 8

About 20% of the role is customer interaction and the rest depends on how well you capture requirements, set expectations and hand over.

## How to work through this module
1. **Study** — read [docs/guide.md](docs/guide.md) and write key points in your own words in [docs/notes.md](docs/notes.md).
2. **Set up** — follow [labs/SETUP.md](labs/SETUP.md).
3. **Practise** — do the labs in order (at least the first two before moving on).
4. **Check** — answer the self-check questions out loud without notes, then update [PROGRESS.md](../PROGRESS.md).

## Labs
- [ ] [Lab 01: Technical discovery checklist + role-play](labs/lab-01-discovery-checklist/README.md)
- [ ] [Lab 02: 10-minute capstone demo](labs/lab-02-demo-video/README.md)
- [ ] [Lab 03: Go-live readiness checklist and runbook](labs/lab-03-go-live-runbook/README.md)

## Self-check (answer aloud, no notes)
- [ ] A customer blocks outbound internet access. How does that change your design?
- [ ] How do you say no to a request that risks the timeline without damaging the relationship?
