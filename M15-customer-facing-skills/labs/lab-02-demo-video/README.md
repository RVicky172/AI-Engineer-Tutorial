# M15 · Lab 02: 10-minute capstone demo

> Module: [Customer-Facing Engineering Skills](../../README.md) · Study first: [docs/guide.md](../../docs/guide.md) · Environment: [labs/SETUP.md](../SETUP.md)

## Goal
Record a 10-minute demo of your capstone and explain the architecture in plain language.

## Steps
1. Structure: problem (1 min) -> architecture diagram (2) -> live demo incl. approval step (4) -> trace of a failure (1) -> cost & metrics (1) -> next steps (1).
2. Write a script and rehearse twice.
3. Record; watch it back; cut jargon.

## Done when
- [ ] Video link in the capstone README
- [ ] `NOTES.md` in this folder explains what you built, what broke, and what you would do differently

## Stretch
Make a 2-minute executive version.

## Your work
Put your code in this folder (e.g. `src/`, `tests/`). Keep a short `NOTES.md` here:

```markdown
## What I built
## Commands to run it
## Results / numbers
## What broke and how I fixed it
## What I'd explain in an interview
```
