# M15 · Lab 01: Technical discovery checklist + role-play

> Module: [Customer-Facing Engineering Skills](../../README.md) · Study first: [docs/guide.md](../../docs/guide.md) · Environment: [labs/SETUP.md](../SETUP.md)

## Goal
Write a 30-question technical discovery checklist for an agent deployment and role-play it with a sceptical 'customer architect'.

## Steps
1. Sections: business goal & success metrics, users, applications/APIs, data, identity, network, security & compliance, operations, constraints/timeline.
2. Write 30 questions; mark the 10 you would ask first.
3. Role-play 30 minutes; record it if possible.
4. Note every question you could not answer or that surprised you; update the checklist.

## Done when
- [ ] `discovery-checklist.md` v2 + 5 lessons from the role-play
- [ ] `NOTES.md` in this folder explains what you built, what broke, and what you would do differently

## Stretch
Turn the answers into a one-page solution proposal with assumptions and risks.

## Your work
Put your code in this folder (e.g. `src/`, `tests/`). Keep a short `NOTES.md` here:

```markdown
## What I built
## Commands to run it
## Results / numbers
## What broke and how I fixed it
## What I'd explain in an interview
```
