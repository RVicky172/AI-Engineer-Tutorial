# M15 · Lab 03: Go-live readiness checklist and runbook

> Module: [Customer-Facing Engineering Skills](../../README.md) · Study first: [docs/guide.md](../../docs/guide.md) · Environment: [labs/SETUP.md](../SETUP.md)

## Goal
Write a go-live readiness checklist and a one-page operational runbook for your capstone.

## Steps
1. Readiness: tests/evals green, security review, IAM reviewed, alarms + on-call, rollback tested, data handling approved, UAT sign-off, hypercare plan.
2. Runbook: how to check health, top 5 alerts and responses, rollback steps, escalation contacts, where logs/traces live.
3. Hypercare plan: daily status format for the first 2 weeks.

## Done when
- [ ] `go-live-checklist.md` and `runbook.md`
- [ ] `NOTES.md` in this folder explains what you built, what broke, and what you would do differently

## Stretch
Write a knowledge-transfer agenda for the customer's ops team.
