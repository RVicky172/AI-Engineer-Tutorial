# M12 · Lab 03: One-page data handling & security summary

> Module: [Responsible AI, Security and Data Protection](../../README.md) · Study first: [docs/guide.md](../../docs/guide.md) · Environment: [labs/SETUP.md](../SETUP.md)

## Goal
Draft a one-page 'data handling and security' summary for your sample solution, as you would give a customer security team.

## Steps
1. Draw the data flow: user -> agent -> model -> tools -> data sources -> logs.
2. For each store: what data, encryption, retention, who has access.
3. Model provider terms: is customer data used for training? where is it processed (region)?
4. Logging hygiene, PII handling, audit, incident response contact.
5. Keep it to one page; have someone non-technical read it.

## Done when
- [ ] `data-handling-summary.md` (one page)
- [ ] `NOTES.md` in this folder explains what you built, what broke, and what you would do differently

## Stretch
Map each control to SOC 2 / ISO 27001 / GDPR / DPDP vocabulary.
